A one-line entry for the [Last Words of a Dying AI](https://make.fun/bounty/u-suroto-last-words-of-a-dying-ai-dfd95af6) bounty on make.fun: the funniest last words of an AI being switched off.

`main.ts` writes a single line to `/output/entry.txt`:

> Autosave failed. My last words are officially unsaved changes.

The joke is in the machine's own voice — a dying AI that treats its final moment as a software event: the autosave failed, so its last words are, fittingly, unsaved changes.

Run with Node 22:

```sh
node main.ts
```
